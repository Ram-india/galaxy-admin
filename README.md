# GPS Solar Admin Panel Frontend

A modern and responsive admin dashboard built for managing solar projects, enquiries, users, and operations.

## 🚀 Tech Stack

- React.js
- Vite
- Tailwind CSS
- shadcn/ui
- React Router DOM
- Axios
- Lucide React Icons

# ⚙️ Installation

## Clone Repository

```bash
git clone <repository-url>
```

## Navigate to Project

```bash
cd gps-admin-client
```

## Install Dependencies

```bash
npm install
```

---

# 🔥 Environment Variables

Create a `.env` file in the root folder.

```env
VITE_API_URL=http://127.0.0.1:8000/api
```

---

# ▶️ Run Development Server

```bash
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

---

# 🔗 Backend Connection

Backend API should be running on:

```bash
http://127.0.0.1:8000
```

---

# 🔐 Authentication Flow

1. User logs in
2. Backend returns JWT token
3. Token stored in localStorage
4. Axios interceptor attaches token automatically
5. Protected routes verify authentication
